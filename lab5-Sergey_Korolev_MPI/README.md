## 1. Цель работы

Модифицировать программу умножения матриц из лабораторной работы №1 для параллельного выполнения по технологии **MPI (Message Passing Interface)**. Провести серию экспериментов с разными размерами матриц и разным количеством вычислительных процессов на суперкомпьютере «Сергей Королёв».

---

## 2. Описание задачи

Выполняется умножение двух квадратных матриц **A** и **B** размера **N×N**:

```
C = A × B,   C[i][j] = Σ A[i][k] * B[k][j]
```

Матрицы генерируются внутри программы псевдослучайными числами в диапазоне **[-10, 10]** с фиксированными seed-значениями (воспроизводимость). Результирующая матрица C на диск **не сохраняется** — фиксируется только **время вычислений**.

---

## 3. Реализация

### 3.1 Алгоритм параллелизации

Использована схема **блочного распределения строк** матрицы A:

1. **Root-процесс (rank 0)** генерирует матрицы A и B
2. `MPI_Bcast` — матрица B рассылается **всем** процессам целиком
3. `MPI_Scatterv` — строки матрицы A **распределяются** между процессами (с учётом остатка: при `N % size ≠ 0` первые процессы получают на одну строку больше)
4. Каждый процесс **локально перемножает** свою часть строк A на полную матрицу B
5. `MPI_Barrier` + `MPI_Wtime()` — замер чистого времени вычислений, синхронизированного между всеми процессами
6. `MPI_Gatherv` — результат собирается на root-процессе

### 3.2 Оптимизация вычислительного ядра

Применён порядок обхода **i-k-j** вместо классического i-j-k:

```cpp
for (int i = 0; i < my_rows; ++i) {
    for (int k = 0; k < N; ++k) {
        double temp = local_A[i * N + k];   // однократное обращение к A
        for (int j = 0; j < N; ++j)
            local_C[i * N + j] += temp * B[k * N + j];
    }
}
```

Это обеспечивает **последовательный доступ к памяти** по строкам B и C → снижение промахов кэша.

## 6. Компиляция и запуск

### Компиляция (на login-узле)

```bash
module load intel/mpi4
mpicxx -O3 main.cpp -o matmulMPI
```


### Скрипт запуска (`startMPI.pbs`)

```bash
#!/bin/bash
#SBATCH --job-name=matmulMPI
#SBATCH --time=0:05:00
#SBATCH --ntasks-per-node=8
#SBATCH --partition=batch
#SBATCH --output=matmul_%j.log
#SBATCH --error=matmul_%j.err

module load intel/mpi4
mpirun -r ssh ./matmulMPI 2000
```

### Отправка задания

```bash
sbatch startMPI.pbs
```

### Проверка статуса

```bash
squeue -u $USER
```

### 7.3 Теоретическая оценка ускорения

При идеальном параллелизме ожидаемое ускорение на **8 процессах** определяется законом Амдала:

```
S(p) = 1 / (f + (1-f)/p)
```

где `f` — доля последовательного кода (рассылка B через `MPI_Bcast`, сборка C через `MPI_Gatherv`).

При матрице 2000×2000 объём пересылок:
- `MPI_Bcast(B)`: 2000×2000×8 байт ≈ **30.5 МБ**
- Коммуникационные издержки существенны при малых N, при больших N — вычисления доминируют
